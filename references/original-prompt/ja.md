# XXD Panel 009 原始プロンプト · 日本語訳

> 閲覧用の忠実な翻訳です。実行時の唯一の基準は[簡体字中国語の原文](zh-CN.md)です。

アップロードした各写真を、それぞれ1枚の独立したハイエンドなデザインポスターにしてください。複数画像を組み合わせず、各写真を個別に出力します。全体は3:4の縦構図を採用し、上下2つの領域の高さは厳密に1:1とし、それぞれ画面の50%を占めます。

上半分には元の写真を残し、被写体の構造、リアルな質感、自然な光と影、元の色彩の雰囲気を維持し、わずかにハイエンドな写真のカラーグレーディングのみを施して、アート雑誌や展覧会写真のような質感を持たせます。画面比率に合わせるため、空、地面、または周囲の背景を自然に拡張できますが、被写体を引き伸ばしたり、歪めたり、変更したりしてはいけません。

下半分では、写真の中で最も識別性の高い**被写体、輪郭、姿勢、物語上の関係性**を抽出し、複雑な情報を唯一の視覚的アンカーへと圧縮して、ミニマルなシルクスクリーン版画とハーフトーン印刷のポスターとして再構成します。写真をなぞったり、豊富なイラストのディテールを加えたりせず、最も重要な形、動作、または空間関係を1つだけ残し、ごくわずかな情報でも被写体を一目で識別できるようにします。

構図は「**1つの被写体、1つの方向、1つの空間関係**」に従います。被写体は通常、小さなスケールを保ち、大面積の余白によって距離感と詩情を生み出します。元画像そのものの関係性に基づき、水平展開、垂直方向への伸長、孤立した浮遊、外側への消散、または浅部から深部への進行のうち、最も自然な構造を1つだけ選び、複数の構図技法を同時に使用しません。1本の地平線、境界、影、またはハーフトーンの帯を用いて空間を確立し、空白そのものを画面の主要な構成要素にすることができます。

配色は写真を直接複製せず、元画像の総合的な色温度、明度、感情を抽出し、**紙の地色 + 主インク色 + 霧層色**という限定的な特色体系へと再整理します。オフホワイト、ウォームグレー、または自然な紙色で大面積の余白を担い、落ち着きと重みのある総合色を1色、主インク色として用い、さらに同系色のより明るく、より灰色がかった色で空気、距離、または階層を表現します。全体を2～3色に抑え、色の面積、明度、ハーフトーン密度で階層を作ります。明確な物語上の意味がある場合にのみ、ごく小面積のアクセントカラーを許可します。

すべての霧、距離、影、消散、空間の移行には、**halftone網点が密から疎へと自然に消えていく表現**を使用し、デジタルぼかしや一般的なグラデーションは使用しません。紙の粒子、シルクスクリーンのインク、わずかな見当ずれ、不均一なインクの乗りを残し、古い紙に実際に印刷されたアート版画のような画面にします。

**ハイエンドな編集感を持つ装飾的な文字システムを少量残します。** 場所の名称だけに限定せず、写真のテーマ、感情、時間、動作、素材、距離、または比喩から、ユーザーが指定した対象言語で極めて短いタイトルを生成し、極小の副文、番号、年、章番号、座標風の数字、アーカイブ記号、または含みのある短文を1つ組み合わせます。文案はやや抽象的、文学的、キュレーション的な語調でもよく、画面を完全に説明する必要はありません。例えば「距離、静止、通過、反響、境界、時間、光、痕跡」などの概念に関するものとし、アートブック、建築雑誌、または独立展覧会の編集注釈のように仕上げます。

文字自体が構図に参加しなければならず、後から余白に貼り付けるものではありません。小さな文字を**地平線に沿って並べる、被写体の輪郭に沿わせる、垂直の視覚軸にする、ハーフトーンの境界をまたがせる、ネガティブ形状の中に隠す、または被写体との間に遮蔽、交差、分断、整列の関係を生じさせる**ことができます。また、極細の縦線、短い横線、番号、ページ番号風の記号によって、大面積の余白との間にリズムを作ることもできます。1つの単語を分解したり、縦組みにしたり、字間を広げたり、一部を図形で隠したりすることを許可しますが、常に読む順序を保ちます。

文字の階層は抑制します。**極めて短い主タイトル1つ + 極小の補助文字1～3組で十分です**。書体はハイエンドなアート出版物とモダニズムのエディトリアルデザインを参照し、抑制の効いたサンセリフ、穏やかなセリフ、またはミニマルなコンデンス書体を使用します。極端な文字サイズの対比、広い字間、細いウェイト、上付き・下付き、小型大文字、非対称レイアウトによって洗練された感覚を生み出します。文字色は主インク色または霧層色と統一し、わずかな見当ずれとインクの粒子を加えることで、文字と図形が同じ1回の印刷に属し、デジタル組版のオーバーレイには見えないようにします。

全体として、**極めて少ない要素、極めて大きな余白、極めて小さな被写体、極めて強い秩序、そして繊細で知的な文字の介入**を追求し、静けさ、孤独、広大さ、含蓄、詩情、知的な趣、収集価値を表現します。複雑な構図、複数の焦点、無意味な装飾、画面を圧迫する大見出し、商業広告の文案、一般的なグラデーション、安っぽいレトロフィルター、テンプレート感を避けます。
