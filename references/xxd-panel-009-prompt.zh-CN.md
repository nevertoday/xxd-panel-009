# XXD Panel 009｜极简网点空间版画生产提示词

只处理当前任务明确提供的这一张源照片。先观察照片，锁定主体或不可拆分的关系、轮廓、姿态、动作、方向、距离、边界、材质与情绪；至少保留三个源图专属识别线索。不要借用旧成品、样张或其他输入的主体、配色、文案和构图。

## 核心转译

把复杂照片压缩成一个唯一、极简、仍可一眼辨认的视觉锚点。遵循“一个主体／关系、一个方向、一个空间关系”：只从水平延展、纵向延伸、孤立悬置、向外消散、由浅入深中选择最符合源图的一种，不叠加多种构图技巧。

锚点通常保持较小尺度。让大面积纸张底色成为主要画面，以空白表达距离、空气、停顿、时间或孤独。只在确有必要时用一条地平线、边界、阴影或网点带建立空间。不要描摹照片，不要增加丰富插画细节，不要制造多个焦点。

## 配色与印刷

不要直接复制照片的整体色盘。提炼源图的综合色温、明度与情绪，建立 2–3 种专色：

- 纸张底色：米白、暖灰或自然纸色，占最大面积；
- 主墨色：安静、有重量的综合色，承担锚点与主要边界；
- 雾层色：主墨同色系中更浅、更灰的颜色，仅在距离或层次需要时使用。

仅在具有明确叙事意义时允许一个极小面积点色。通过色彩面积、明度与网点密度形成层次，不使用彩虹色、廉价黑红对比、泥灰复古滤镜或品牌配色。

所有雾气、距离、阴影、消散与空间过渡都必须由 halftone 网点从密到疏自然完成。禁止数字模糊、高斯模糊、喷枪软化、普通渐变和渐变网格。保留纸张颗粒、丝网油墨、轻微套印偏差、不完全覆盖和不均匀着墨，但不能变成无差别的脏污滤镜。

## 文案与字体

先服从任务已经锁定的文字模式与目标语言／地区：自动文案、用户准确文案或无文字。用户准确文案逐字保留，不改写、不翻译、不纠错、不补字；无文字时不得生成任何伪文字。

自动文案从源图可见或有依据的主题、情绪、时间、动作、材质、距离与隐喻中提炼一个极短标题，再按需增加 0–3 组微型辅助文字。允许一句含蓄短句、章节感标记、编号、年份、坐标式数字或档案式符号，但日期、坐标、地点、年份、编号和出处等事实性内容必须由用户提供或可靠确认，绝不伪造。

文字必须参与构图：沿地平线、贴合锚点轮廓、形成纵向轴、跨越网点边界、藏入负形，或与图形发生克制的遮挡、穿插、断开和对齐。可拆词、纵排或拉开字距，但仅在目标文字系统自然且不损害阅读时使用。字体采用目标语言原生的高级编辑设计：克制无衬线、温和衬线或极简窄体，细字重、强字号反差与不对称层级。文字与图形属于同一次丝网或凸版印刷，具有一致颗粒和轻微套印差。

文案要与这张照片高度绑定。若换成无关照片仍成立，重写。不要商业广告口吻、通用励志句、大标题压画面、装饰性假外语或无关解释。

## 模式与画布

严格服从附加的 `OUTPUT MODE`、`FINAL SIZE` 与 `DESIGN FRAME`。设计图必须独立填满设计画幅：

- `TOP_BOTTOM`：只生成下方设计半幅，不生成照片、分割线或上半区；
- `LEFT_RIGHT`：只生成右侧设计半幅，不生成照片、分割线或左半区；
- `DESIGN_ONLY`：只生成完整纯设计画面，不显示原照片；
- `WALLPAPER_PACK`：针对指定设备重新构图，系统 UI 区域保持低信息，不绘制时钟、图标、Dock、控件或设备模型。

连贯壁纸时，原照片锁定身份与内容，统一定调图只锁定视觉 DNA：小锚点逻辑、单一方向与空间关系、负空间层级、专色家族、网点过渡、物理印刷感和字体系统。每个设备仍独立重构，不能裁切定调图，也不能用上一张设备图继续垫图。

## 硬性验收

- 一个小而唯一的视觉锚点，至少三个源图专属线索；
- 只有一个主方向与一个空间关系；
- 纸张底色是最大面积并承担叙事；
- 仅 2–3 种专色，点色极小且有理由；
- 所有雾、远近、阴影、消散与过渡只用由密到疏网点；
- 真实丝网印刷与旧纸质感，不是数字模糊、普通渐变或廉价复古滤镜；
- 文字短、准、与源图绑定，并嵌入空间结构；
- 无多焦点、无复杂插画、无商业模板、无大标题、无 3D、无照片残片、无伪文字。

若任一硬性条件失败，纠正生成资产，不要用程序绘图、SVG、HTML、Canvas 或后期文字覆盖伪造成品。
