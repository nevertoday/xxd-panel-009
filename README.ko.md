> 작은 앵커 · 넓은 여백 · 하나의 공간 관계 · 별색 체계 · 하프톤 실크스크린

XXD Panel 009는 Codex와 호환 에이전트를 위한 이미지 생성 Skill입니다. 원본 사진의 주제, 윤곽, 자세와 서사 관계를 고정하고 복잡한 정보를 작지만 한눈에 알아볼 수 있는 하나의 시각적 앵커로 압축합니다. 방향과 공간 관계를 하나씩만 선택하고, 넓은 종이색 여백이 거리·공기·멈춤·시간을 맡게 합니다.

색은 종이 바탕, 주 잉크, 필요한 경우의 안개층으로 제한합니다. 안개·거리·그림자·소멸·전환은 모두 망점이 촘촘함에서 성김으로 변하며 표현하고 디지털 블러나 일반 그라데이션은 쓰지 않습니다. 종이결, 실크스크린 잉크, 미세한 판 어긋남과 고르지 않은 착묵을 남기며, 글자는 수평선·윤곽·축·망점 경계·네거티브 셰이프 안으로 들어갑니다.

## 왜 009이 필요한가요

일반적인 ‘고급 빈티지 포스터’는 주제를 작게 줄이고 낡은 종이를 덮은 뒤 영어 번호와 부드러운 그라데이션을 붙이는 템플릿으로 쉽게 무너집니다.

009은 순서를 뒤집습니다.

```text
원본 사실 고정 → 하나의 시각적 앵커로 압축 → 방향과 공간 관계를 하나씩만 선택 → 종이 여백이 거리와 시간을 담당 → 종이／주 잉크／안개 별색 구성 → 모든 전환을 망점 밀도로 제작 → 글자를 공간 구조에 결합
```

무관한 사진으로 바꿔도 앵커, 방향, 공간 관계, 망점의 흐름, 종합 색온도와 문구가 거의 그대로 성립한다면 009가 아닙니다.

## 009의 시각적 원칙

- **작은 앵커 하나:** 최소 세 가지 원본 고유 단서로 주제, 윤곽, 자세, 동작과 관계를 적은 정보 안에서도 식별합니다.
- **방향 하나:** 수평 확장, 수직 연장, 고립된 부유, 바깥으로 소멸, 얕은 곳에서 깊은 곳으로의 후퇴 중 하나만 선택합니다.
- **공간 관계 하나:** 수평선, 경계, 그림자 또는 망점 띠 하나면 충분합니다.
- **여백이 주제:** 종이색이 가장 넓은 면적을 차지하고 거리, 공기, 멈춤, 시간 또는 고독을 맡습니다.
- **별색 2–3개:** 종이 바탕, 조용하고 무게감 있는 주 잉크, 필요할 때만 더 옅고 회색인 동계열 안개층입니다.
- **전환은 망점만:** 안개, 깊이, 그림자와 소멸은 촘촘함에서 성김으로 가는 하프톤으로 만듭니다.
- **물리적 인쇄감:** 종이결, 잉크, 미세한 판 어긋남과 착묵의 흔들림을 남기되 값싼 오염 필터는 피합니다.
- **지적인 글자 개입:** 극히 짧은 제목과 소량의 미세 문자를 수평선, 윤곽, 축, 망점 경계 또는 네거티브 셰이프에 넣습니다.

## 네 가지 출력, 하나의 망점 공간 논리

네 가지 모드는 하나만 또는 여러 개를 함께 선택할 수 있습니다. `1`, `1+3`, `1、2、4`, `전체`라고 답하면 Skill이 중복을 제거하고 1→4 순서로 실행합니다. 각 모드는 별도 작업 폴더에 독립적으로 출력되며 한 장의 모음 이미지로 합치지 않습니다. `전체`는 원본 한 장당 PNG 7개(일반 모드 각 1개＋배경화면 4개)를 만듭니다. 크기는 모드별로 표시해 같은 답변에서 지정할 수 있고, 지정하지 않은 일반 모드는 원본에 맞춥니다. 문구는 기본적으로 선택한 모드가 공유하며 모드별 지정도 가능합니다.

| 모드 | 크기 규칙 | 결과물 |
| --- | --- | --- |
| `top-bottom` | 원본 적응형 | 위에는 전체 원본, 아래에는 009 미니멀 망점 공간 판화. 두 패널이 원본 크기를 유지하며 정확히 50/50 |
| `left-right` | 원본 적응형 | 왼쪽에는 전체 원본, 오른쪽에는 009 미니멀 망점 공간 판화. 두 패널이 원본 크기를 유지하며 정확히 50/50 |
| `design-only` | 원본 적응형 | 원본 사진은 보이지 않고 변환 디자인만 표시. 원본 비율과 크기 유지 |
| `wallpaper-pack` | 기기별 네 가지 크기 | 휴대전화, iPad, 데스크톱, 어린이용 스마트워치 PNG 개별 출력 |

정확한 사용자 픽셀 > 지정 비율 또는 용도 > 일반 모드의 원본 적응형 순서입니다. 원본 `009.md`의 3:4는 초기 창작 캔버스일 뿐 현재 Skill의 숨은 기본값이 아닙니다.

짝을 이루는 모드의 사진은 절제된 색 보정과 필요한 환경 확장만 적용해 사실성을 지킵니다. 디자인 단독과 배경화면은 사진을 근거로 사용하지만 원본을 보여 주지 않습니다.

### 배경화면 세트: 연결형 또는 독립형

배경화면에는 숨은 기본 크기가 없습니다. 일반 프리셋은 휴대전화 `1440×3200`, iPad `2048×2732`, 데스크톱 `3840×2160`, 스마트워치 `1024×1024`이며 기기별 사용자 지정 크기도 가능합니다.

- **연결형 세트(권장):** 먼저 iPad 기준 작품을 생성하고 승인합니다. 나머지 세 기기는 원본 사진＋동일한 기준 작품을 참조해 각 화면에 맞게 새로 구성합니다.
- **독립형 네 작품:** 각 기기는 원본 사진만 참조하며 작은 앵커 위치, 단일 방향, 공간 관계, 별색 조합, 망점 흐름과 글자 개입을 각각 탐색합니다.

연결형은 크롭이 아닙니다. 네 장 모두 따로 생성하고 구성하며 검수하고, iPad→휴대전화→데스크톱→스마트워치 순으로 참조를 이어 붙이지 않습니다.

## 문구는 공간과 판화 구조의 일부여야 합니다

생성 전에 자동 문구, 사용자 지정 문구, 무문자 출력 중 하나를 선택합니다. 문구가 있으면 대상 언어나 지역도 지정합니다.

자동 문구는 사진에서 보이거나 근거가 있는 주제, 감정, 시간, 동작, 재료, 거리 또는 은유에서 극히 짧은 제목을 만듭니다. 추상적·문학적·큐레이터적일 수 있지만 이 이미지와 긴밀히 묶여야 합니다.

필요할 때 미세 주석, 짧은 문장, 장 표시, 번호, 연도, 좌표형 숫자 또는 아카이브형 기호를 0–3개 더합니다. 날짜·좌표·장소·연도·번호·출처는 사용자 제공이나 신뢰할 수 있는 근거가 있어야 하며 고급스러워 보이려고 꾸며 내지 않습니다.

사용자가 완성 문구를 주면 그대로 유지합니다. 방향이나 수정 가능한 초안일 때만 대상 독자, 목적, 필수 단어, 어조, 함의를 보존하며 다듬습니다.

언어는 명령문의 언어가 아니라 의도한 독자를 따릅니다.

```text
목표 시장 또는 독자 > 지정한 결과물 언어 > 방향 지시 언어; 모두 불분명하면 생성 전에 질문
```

일본판은 자연스러운 현대 일본어를, 한국 독자용은 자연스러운 현대 한국어와 정확한 띄어쓰기를, 영국판은 영국 영어를 사용합니다. 아랍어판은 기본적으로 자연스러운 현대 표준 아랍어와 올바른 오른쪽에서 왼쪽으로 흐르는 구성을 사용합니다. 외모, 옷, 풍경, 간판으로 국적을 추측하지 않으며 가짜 외국어 문자를 쓰지 않습니다.

## 정확한 기하는 코드가, 작품은 이미지 생성이 맡습니다

이미지 모델이 원본에 묶인 작은 앵커, 하나의 방향과 공간 관계, 넓은 종이색 여백, 제한된 별색, 망점 밀도 전환, 물리적 실크스크린 감각과 공간 안의 글자를 만듭니다. `scripts/compose_panel.py`는 캔버스 계획, 정확한 50/50 래스터 합성, 최종 크기와 검수만 수행하며 프로그램 그림으로 결과물을 위조하지 않습니다.

```bash
python3 scripts/compose_panel.py --plan --layout top-bottom --source photo.png
python3 scripts/compose_panel.py --plan --layout left-right --size 2560x1440
python3 scripts/compose_panel.py --audit result.png --layout design-only --size 2048x2048
```

정확한 상하 캔버스는 전체 높이, 좌우 캔버스는 전체 너비가 짝수여야 합니다. 요청 픽셀을 몰래 변경하지 않습니다.

## 경계와 신뢰

- 각 사진은 독립된 작업 안에서만 사용하며 다른 입력, 과거 결과, 예시의 피사체, 색, 문구, 구도를 빌리지 않습니다.
- 호출할 때마다 새 작업 폴더를 만들고 원본과 조건이 같아도 새로 생성합니다.
- 결과물은 PNG 비트맵이며 SVG, HTML, Canvas, 프로그램 드로잉 대체물이 아닙니다.
- 설정된 비트맵 브리지는 정제된 상태만 출력하며 공급자, 엔드포인트, 헤더, 인증 정보, 프롬프트, 응답 본문을 노출하지 않습니다.
- 선택한 일반 모드마다 파일 1개를 반환하고, `wallpaper-pack`을 선택하면 독립 배경화면 4개를 추가합니다. `전체`는 원본 한 장당 PNG 7개를 네 개의 동급 모드 폴더에 저장하며 모음 이미지로 합치지 않습니다.

로컬 합성에는 Python 3와 Pillow가 필요합니다. 안전한 비트맵 브리지는 Python 3.11 이상의 `tomllib`을 사용합니다. 이미지 생성에는 내장 래스터 기능이 있는 호스트 에이전트 또는 이미 설정된 호환 경로가 필요합니다.
